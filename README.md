# XOR Encryption-Decryption Tool 🔐

A simple command-line encryption/decryption program using XOR in C++.

## Features
- Encrypt and decrypt text with a single-character key
- Includes color settings and a clean menu interface

## How to use
1. Compile with any C++ compiler (e.g., `g++ Encryptor.cpp -o Encryptor`)
2. Run the executable and follow the menu
